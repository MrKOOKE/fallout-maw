# Системный компендиум журналов

Компендиум `fallout-mav-journals` поставляется вместе с системой и содержит журналы
`Fallout-Игрокам` и `Fallout-Мастерам` из мира разработчика `fallout`.

Исходные журналы редактируются в мире. Чтобы обновить поставляемую версию, закройте
Foundry VTT и выполните из каталога системы:

```powershell
npm run build:journals
npm run check:journals
```

Сборщик сохраняет идентификаторы журналов и страниц, удаляет права конкретных
пользователей и служебные ссылки на мир, копирует используемые изображения в
`assets/journals` и заменяет пути `worlds/fallout/...` на переносимые пути
`systems/fallout-maw/...`.

Каталоги `packs/fallout-mav-journals` и `assets/journals` являются результатом
сборки. Их нужно включать в ZIP или другой публикуемый пакет системы.
