# Черновик бонусов гражданской одежды

Текущий LevelDB мира не читался и не изменялся. Старые ActiveEffect-бонусы не загружались и не использовались.
Старые автоматически собранные описания также исключены: они пересказывают те же случайные бонусы.

## Метод

- Сначала назначена смысловая специализация по канонической роли, профессии, фракции, названию и изображению.
- Для безымянных полных масок вручную зафиксирован животный/визуальный архетип.
- Старые классы, рецепты и компоненты используются только как технические ограничения.
- Распределитель выбирает только среди смыслово допустимых навыков и контролирует глобальный перекос.
- Базовый навык каждого канонического или вручную проверенного предмета зафиксирован; баланс частот влияет только на вторичные направления.
