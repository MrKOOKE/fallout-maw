Этот файл не является готовой записью в мир. Текущий LevelDB мира не читался и не изменялся.

## Зафиксированные правила

- Старые ActiveEffect-бонусы навыков признаны случайными и полностью исключены из доказательной базы.
- Старый мир используется только для классов, рецептов, объёма текстиля, компонентов свойств и исторических цен.
- Целевые папки: `Снаряжение / Одежда / <класс>` и `Снаряжение / Головные уборы / <класс>`.
- Маски, очки, капюшоны и прочие предметы головы относятся к головным уборам, но сохраняют реальные занимаемые слоты.
- Базовая сумма навыков одежды: D 20, C 30, B 50, A 70, S 90.
- Бонус одного навыка не может превышать 30.
- Положительные отклонения сверх бюджета и отдельные особые функции должны иметь собственные компоненты и цену.

## Контроль распределения

- До лорной проверки конкретные бонусы навыков не назначаются.
- После назначения доля каждого навыка по сумме очков должна находиться ориентировочно в коридоре 5–12%.
- Отношение самого частого навыка к самому редкому не должно превышать 2,25.
- Баланс частот не может переопределять смысл предмета: если корректного кандидата нет, предмет остаётся в очереди ручной проверки.
- Проверяется не только общая сумма, но и представленность каждого навыка внутри типов и классов, где размер группы это позволяет.
