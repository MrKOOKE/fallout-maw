# Черновик перебаланса мили-оружия

Мир прочитан только из мировых Items. Актёры и паки не читались; записи в мир не было.

## Что делает код на самом деле

1. Урон успешного контакта делится на дробь.
2. Каждая доля дроби отдельно делится между типами урона.
3. Защита и сопротивление применяются к каждой получившейся доле отдельно.
4. «Дробное воздействие» оставляет один бросок попадания и одну часть тела, но не склеивает доли обратно перед защитой.

Следовательно, `дробь 4 + два типа урона` даёт восемь самостоятельных проверок защиты. Поэтому высокий сырой урон для такой милишки обязателен, а не является бесплатным усилением.
