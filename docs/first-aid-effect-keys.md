# Ключи эффектов первой помощи

Система поддерживает четыре процентных ключа:

| Ключ | Носитель | Действие |
| --- | --- | --- |
| `system.firstAid.outgoingEffectivenessPercent` | оказывающий помощь | Изменяет силу всех числовых эффектов предмета первой помощи |
| `system.firstAid.incomingEffectivenessPercent` | получатель | Изменяет силу всех числовых эффектов предмета первой помощи |
| `system.firstAid.durationPercent` | получатель | Изменяет только длительность основного эффекта |
| `system.firstAid.withdrawalResistancePercent` | получатель | Уменьшает одновременно силу и длительность отдачи |

Обычное входящее и исходящее лечение продолжает действовать только на лечение. Эффективность первой помощи применяется дополнительно к нему и также затрагивает периодическое лечение, изменения потребностей, конечностей и произвольные числовые изменения Active Effect. Снятие эффектов остаётся дискретным действием и не масштабируется.

Изменения внутри каждого отдельного ключа объединяются по обычным правилам Active Effect, а полученные процентные множители перемножаются:

```text
сила = результат проверки × (1 + исходящая эффективность / 100)
        × (1 + входящая эффективность / 100)

лечение = сила × (1 + исходящее лечение / 100)

длительность = базовая длительность × (1 + длительность / 100)

сила отдачи = сила × max(0, 1 - сопротивление отдаче / 100)
длительность отдачи = базовая длительность отдачи
                      × max(0, 1 - сопротивление отдаче / 100)
```

Отрицательные итоговые множители ограничиваются нулём. Числовая сила и длительность округляются вниз; ненулевой эффект сохраняет минимальную величину `1`. При полном обнулении эффект не создаётся: `-100%` эффективности отключает соответствующую силу, а `100%` сопротивления полностью убирает отдачу.
