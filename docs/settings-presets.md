# Пресеты настроек

Менеджер **Пресеты настроек** переносит только явно помеченные настройки мира. Настройки клиента и пользователя, состояние миграций, runtime-данные интерфейса и служебные состояния мира в пресеты не входят.

Основной пресет имеет постоянный ID `fallout-maw`. Его можно менять и переименовывать, но нельзя удалить. Новый пресет всегда создаётся как полная независимая копия основного. При первом открытии мира без активного пресета система создаёт для него личную копию актуального `fallout-maw`, называет её именем мира и применяет её настройки. Выбранный пресет хранится отдельно в каждом мире, а любое последующее изменение управляемой настройки автоматически создаёт его новую полную ревизию.

Системные JSON находятся в `storage/settings-presets/<preset-id>.json`. Использованные файлы дополнительно копируются в `worlds/<world-id>/settings-presets`, поэтому уникальные пресеты мастера восстанавливаются после полной замены папки системы. При совпадении ID системный файл считается авторитетным; пресеты с другими ID не затрагиваются.

Импорт одного JSON с существующим ID полностью заменяет этот пресет. Новый ID добавляет новый пресет. Удаление обычного пресета физически удаляет его системный JSON и резервную копию активного мира; списков скрытых ID и tombstone-файлов менеджер больше не создаёт. Старое поле состояния `removedPresetIds` игнорируется, поэтому ранее лишь скрытые файлы снова видны и их можно удалить заново. Файловое удаление требует установленного серверного адаптера из `server-patches` и полного перезапуска Foundry после его обновления. Старый экспорт baseline допускается только при импорте и преобразуется в новый пресет с новым ID.

У каждого пресета есть собственная история сохранений. Кнопка с камерой записывает полную текущую версию внутрь этого же JSON, а кнопка истории показывает все версии и позволяет полностью установить выбранную. При создании нового пресета история главного пресета не копируется.

В зарегистрированных окнах настроек кнопка **«Мигрировать из других пресетов»** открывает выбор пресета или одной из его сохранённых версий, затем показывает сравнение. Можно заменить настройку целиком либо отметить отдельные поля. Для типов и рас переносится цельный объект со всеми вложенными данными; перенос типа включает его расы. В каталоге способностей можно переносить категорию целиком или отдельные способности с выбором целевой категории.

Публичный API доступен как `CONFIG.FalloutMaW.settingsPresets`: `list`, `get`, `active`, `create`, `activate`, `rename`, `remove`, `saveVersion`, `restoreVersion`, `removeVersion`, `migrate`, `import`, `export`, `refresh` и `flush`.
