# Fallout-MaW

Игровая система Fallout-MaW для Foundry Virtual Tabletop 14.

Настройки мира можно сохранять, переключать и передавать другим мастерам через менеджер пресетов Fallout-MaW.

## Лаунчер и выпуски

Проект включает Windows-лаунчер и локальный publisher: первая установка получает полный пакет, последующие версии — подписанные инкрементальные патчи с сохранением `storage`. Инструкция автора: [docs/launcher-and-releases.md](docs/launcher-and-releases.md).
